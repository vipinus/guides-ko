# 01 · 중국 IP가 필요한 서비스

기준은 하나뿐입니다. 서비스가 내 출발지 IP가 중국 본토가 아니라는 것을 알아채면 접속을 거부하거나 기능을 줄입니다. 아래 표는 차단이 엄격한 순서로 정리했습니다.

| 분류 | 예 | 중국 IP 없이 쓰면 | IP 말고 확인하는 것 |
|---|---|---|---|
| 동영상 | 아이치이(iQIYI), 텐센트 비디오, 요우쿠(Youku), 망고TV, 빌리빌리의 일부 애니메이션 | 중국 본토에서만 볼 수 있다는 안내가 뜨거나 무료 콘텐츠만 볼 수 있음 | 앱 스토어 지역, 계정 가입 지역 |
| 음악 | 넷이즈 클라우드 뮤직(NetEase Cloud Music), QQ뮤직, 쿠거우(Kugou) | 수많은 곡이 회색으로 비활성화되어 재생되지 않음 | 없음 |
| 행정 서비스 | 국가 정무 서비스 플랫폼, 각 성의 정무 서비스 사이트, 세무, 사회보험, 주택 공적금 | 페이지가 열리지 않거나 인증 코드가 오지 않음 | 전화번호, 얼굴 인식 |
| 교육 | 학신망(CHSI), 학위 인증 사이트, 대학 학사 관리 시스템 | 열리지 않거나 극도로 느림 | 없음 |
| 교통 | 12306(중국 철도 예매), 항공사 웹사이트 | 열리지 않거나 결제 실패 | 전화번호, 결제 |
| 금융 | 인터넷 뱅킹, 모바일 뱅킹, Alipay, WeChat Pay | 로그인이 리스크 관리에 걸리고 이체 실패 | SIM 카드, 기기 지문, 얼굴 |
| 게임 | 중국 서버 PC·모바일 게임 | 로그인은 되지만 지연이 크고 접속이 끊김 | 실명 인증 |
| 생활 | 메이퇀(Meituan), 어러머(Ele.me), 디디(DiDi), 타오바오 일부 기능 | 위치 오류, 주문 실패 | 위치, 전화번호 |
| 라이브 방송 | 더우인(Douyin), 콰이서우(Kuaishou), 더우위(Douyu) | 일부 지역에서 볼 수 없음 | 없음 |

## 꼭 구분할 점

**'중국 IP가 필요한 것'과 '중국 전화번호가 필요한 것'은 별개입니다.** 동영상과 음악은 IP만 보므로 IP를 바꾸면 됩니다. 행정 서비스, 은행, 표 예매는 IP 외에도 SMS 인증 코드를 받고 얼굴 인식을 통과해야 합니다. IP가 해결하는 것은 '열리느냐'이고, 그 뒤의 인증은 본인의 중국 전화번호와 신분 서류에 달려 있습니다.

## IP 문제를 해결하는 방법

트래픽을 먼저 중국 본토의 서버로 보내고, 그 서버가 목적지에 대신 접속합니다. 방법은 세 가지로, 클라이언트, 웹 프록시, 공유기가 있습니다. 고르는 법은 자매 저장소의 [상황별로 어떤 연결 방식이 맞을까](../network/02-choose-your-connection-method.md)를 보세요.
