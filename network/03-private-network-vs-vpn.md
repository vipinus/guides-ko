# 03 · 사설망(Tailscale)은 VPN과 무엇이 다르고 언제 쓰나

> 웹사이트 버전(더 자세함): https://www.leotun.com/ko/guides/tailscale-mesh?utm_source=github&utm_content=network-03

사설망 항목은 Tailscale을 씁니다. WireGuard 기반의 네트워크 도구이고, 컨트롤 서버는 LeoTun이 직접 운영하며 이 사이트 계정으로 로그인합니다. AnyConnect나 OpenVPN 같은 '연결형' VPN과는 다른 것입니다.

## 세 가지 차이

| | 연결형 VPN(AnyConnect / OpenVPN / Hiddify) | 사설망(Tailscale) |
|---|---|---|
| 연결 | 매번 연결을 누르고, 끊기면 다시 연결합니다 | 한 번 로그인하면 계속 온라인이고, 네트워크를 바꿔도 자동으로 복구됩니다 |
| 출구 | 연결하면 모든 트래픽이 출구를 거칩니다 | 출구는 선택 사항입니다. 고르지 않으면 일반 인터넷 트래픽은 현지에서 나가고 사설망 안 기기끼리의 트래픽만 암호화됩니다. 지역의 출구를 골랐을 때만 VPN과 같아집니다 |
| 기기 간 접속 | 없음 | 같은 계정의 휴대폰, 컴퓨터, NAS가 포트 포워딩이나 공인 IP 없이 서로 바로 접속합니다 |

## 써야 할 때

- 기기가 여러 대이고, 한 번 설정하면 계속 온라인이기를 원할 때.
- 집의 NAS, 컴퓨터, 카메라에 밖에서 접속해야 할 때. 양쪽 모두 사설망에 로그인하면 같은 LAN에 있는 것처럼 기기 이름으로 바로 연결됩니다.
- 오래 연결되어 있어야 하는 기기. 세션 시간 제한이 없습니다.

## 다른 방법이 더 맞을 때

- 잠깐 한 번만 쓰고 싶을 때: QR 코드로 Hiddify를 가져오거나 AnyConnect를 설치하는 편이 빠릅니다.
- 기기에서 이미 회사 VPN이나 다른 네트워크 소프트웨어를 쓰고 있을 때: 둘이 DNS와 라우팅을 두고 충돌하며, 중국 동영상을 볼 때 저작권 안내가 뜨거나 회사 인트라넷이 열리지 않는 증상이 나타납니다. 웹 프록시처럼 브라우저에만 영향을 주는 방식을 쓰세요.
- UDP를 제한하는 학교나 회사 네트워크: WireGuard는 UDP 위에서 돌아가므로 중계에만 의존하게 되어 느립니다. AnyConnect로 바꾸세요.

## 만료와 기기 수

기기의 로그인 유효 기간은 계정의 만료일을 따릅니다. 만료되면 몇 분 안에 오프라인이 되고, 연장한 뒤 다시 로그인하면 됩니다. 동시 접속 기기 수는 요금제에 따라 다르고(개인 2대, 패밀리 4대, 기업 8대) 다른 연결 방식과 한도를 함께 씁니다. 동시 접속 수가 요금제 한도를 넘으면 계정 유형을 잠시 올렸다가(남은 기간은 가격 기준으로 같은 가치로 환산) 일이 끝나면 되돌리면 됩니다.
