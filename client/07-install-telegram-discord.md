# 07 · Telegram과 Discord 설치하기

둘 다 해외에서 널리 쓰는 그룹 채팅 도구이고, 저희 고객 지원 그룹도 여기에 있습니다. 설치 자체는 어렵지 않고, 걸리는 곳은 대개 '앱 스토어가 열리지 않는다'입니다.

## Telegram

| 플랫폼 | 설치 방법 |
|---|---|
| Windows / macOS / Linux / Android | [이 사이트의 문의 페이지](https://www.leotun.com/ko/contact?utm_source=github&utm_content=client-07)에서 공식 버전과 똑같은 설치 파일을 배포합니다(Android는 공식 전체 APK라 Google Play가 필요 없습니다). 공식 사이트 <https://desktop.telegram.org>나 Google Play에서 받아도 됩니다 |
| iOS | App Store에서만 받을 수 있습니다. 스토어 지역 문제는 [앞의 글](06-ios-app-store.md)을 보세요 |

가입하려면 SMS를 받을 수 있는 휴대폰 번호가 필요합니다. 가입한 뒤 사용자 이름을 정하면 다른 사람이 내 번호를 몰라도 됩니다.

## Discord

| 플랫폼 | 설치 방법 |
|---|---|
| Windows / macOS / Linux | 공식 사이트 <https://discord.com/download> |
| Android | 공식적으로는 Google Play에만 있습니다. Play를 설치할 수 없는 휴대폰은 분할 패키지(.apks)를 쓸 수 있는데, 먼저 오픈소스 설치 도구 SAI를 설치해야 하고 arm64 기기만 지원합니다 |
| iOS | App Store |

## 설치한 뒤

- 그룹에 들어가기 전에 그룹 규칙을 읽으세요. 대부분의 그룹은 광고를 금지합니다. 질문하기 전에 먼저 그룹 기록을 검색하세요. 이미 답이 있는 질문이 많습니다.
- 설치가 안 되거나 실행하자마자 꺼지면 시스템 버전과 기기 모델을 고객 지원에 알려 주세요. 대부분 모델이나 버전이 맞지 않는 경우입니다.
