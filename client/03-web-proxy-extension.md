# 03 · 웹 프록시: ZeroOmega 확장 프로그램을 두 단계로 설정하기

> 웹사이트 버전(더 자세함): https://www.leotun.com/ko/guides/web-proxy?utm_source=github&utm_content=client-03

웹 프록시는 **이 브라우저만** 회선으로 보내고, 시스템의 다른 프로그램은 건드리지 않습니다. 클라이언트 설치도, 관리자 권한도 필요 없고, '연결됨' 상태라는 것이 없으니 구조상 끊길 연결도 없습니다. 회사 컴퓨터, 이미 회사 VPN에 연결된 컴퓨터, 브라우저 하나만 회선을 쓰게 하고 싶을 때 알맞습니다. 언제 웹 프록시를 쓰고 언제 VPN이 꼭 필요한지는 [네트워크 가이드 02](../network/02-choose-your-connection-method.md)를 보세요.

## 두 단계

1. **확장 프로그램 설치**: Chrome / Edge / Firefox에 ZeroOmega(SwitchyOmega의 후속판)를 설치합니다. [웹사이트의 웹 프록시 페이지](https://www.leotun.com/ko/httpproxy?utm_source=github&utm_content=client-03)에 브라우저별 설치 링크가 있습니다.
2. **가져오기**: 웹사이트에 로그인해 웹 프록시 페이지에서 원하는 지역의 국기를 누르면(또는 '모든 지역 가져오기 링크 복사'를 눌러 모든 지역을 한 번에) 설정 링크가 복사됩니다. 확장 프로그램의 'Import/Export'(가져오기/내보내기)를 열고 'Restore from online'(온라인에서 복원)에 붙여 넣은 뒤 'Restore'(복원)를 누르세요. 지역, 주소, 암호화 방식이 한 번에 들어가며 손으로 입력할 것은 없습니다.

그다음 확장 프로그램 아이콘을 눌러 지역을 고르고, 브라우저가 띄우는 로그인 창에 웹사이트 계정과 비밀번호를 입력합니다. 지역을 바꾸려면 아이콘 메뉴에서 다른 지역을 누르고, 현지 인터넷으로 직접 연결하려면 'Direct'(직접)로 바꾸세요.

## 이런 경우에는 기기 전체를 연결하는 방식을 쓰세요

- 동영상·음악 앱과 플레이어: 대부분 브라우저의 프록시를 쓰지 않아서 '웹페이지는 열리는데 동영상은 재생되지 않는' 상황이 됩니다.
- 휴대폰 앱, 게임, 데스크톱 프로그램. Dropbox 같은 프로그램의 프록시 설정은 암호화되지 않은 HTTP / SOCKS5만 받는데, 실제로는 프록시가 암호화되어야 하므로 이 사이트의 웹 프록시를 거기에 넣을 수 없습니다. 대신 Hiddify로 기기 전체를 맡기세요. [10](10-app-proxy.md)을 보세요.
- 해외에서 텐센트 비디오나 아이치이(iQIYI) 보기: 동영상 사이트는 IPv6와 DNS도 확인하는데, 웹 프록시는 이 부분을 처리하지 않습니다. 기기 전체를 연결하는 VPN을 쓰세요.

## 자주 묻는 질문

| 증상 | 원인 |
|---|---|
| 로그인 창이 계속 뜸 | 계정이 만료되었거나 비밀번호가 틀렸습니다 |
| 어떤 사이트는 안 열리고 나머지는 괜찮음 | 확장 프로그램의 'auto switch'(자동 전환) 규칙이 그 사이트를 직접 연결로 보냈습니다. 전역 프록시 모드로 한 번 시도해 보세요 |
| 중국에서 HTTPS 사이트만 열림 | 일반 HTTP는 전송 도중 내용이 바뀌어 암호화된 연결만 통과합니다. 요즘은 거의 모든 사이트가 HTTPS입니다 |
| 느림 | 지역을 바꾸세요. 프록시와 VPN은 같은 서버를 씁니다 |
