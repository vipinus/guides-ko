# 10 · Dropbox 같은 프로그램이 HTTP / SOCKS 프록시를 요구할 때

> 웹사이트 버전(더 자세함): https://www.leotun.com/ko/guides/app-proxy?utm_source=github&utm_content=client-10

**먼저 현실부터: 프록시는 암호화되어야 합니다.** 암호화되지 않은 프록시(일반 HTTP, SOCKS4, SOCKS5)는 중국 네트워크에서 식별되어 방해를 받습니다. 얼마 지나지 않아 느려지거나 끊기고, 계정과 비밀번호도 평문으로 오갑니다. 오래 쓸 수 있는 것은 암호화된 연결뿐이라 이 사이트의 웹 프록시는 처음부터 끝까지 암호화된 연결을 씁니다. **HTTP / SOCKS5만 받는 프로그램이라면 Hiddify로 컴퓨터 전체를 맡기세요**(아래 참고).

Dropbox, Telegram Desktop, Steam, 클라우드 드라이브 클라이언트, 개발 도구 같은 독립 프로그램은 브라우저 설정을 읽지 않고, 자체 프록시 설정은 암호화되지 않은 HTTP / SOCKS5만 받습니다. 양쪽이 맞지 않으니 프록시를 입력해도 연결되지 않습니다. 해결책은 **프록시를 입력하지 않는 것**입니다. Hiddify로 컴퓨터 전체를 회선으로 보내고, 프로그램의 프록시는 '프록시 없음'으로 두세요.

## 프록시를 입력했는데도 연결되지 않는 이유

| 원인 | 설명 |
|---|---|
| 형식이 맞지 않음 | 프로그램이 제공하는 것은 HTTP, SOCKS4, SOCKS5뿐이고 모두 암호화되지 않습니다. 이 사이트의 프록시는 암호화가 필수라 입력할 수 없습니다 |
| 인터넷에서 찾은 암호화되지 않은 프록시 | 잠깐은 연결되다가 방해를 받아 됐다 안 됐다 합니다 |
| 트래픽 일부만 처리 | 많은 프로그램이 로그인과 동기화에만 프록시를 쓰고, 업데이트·통화·LAN 동기화는 여전히 직접 연결합니다. HTTP 프록시는 게임과 통화의 UDP 트래픽을 아예 전달하지 않습니다 |
| 프로그램마다 따로 관리 | 지역이나 비밀번호를 바꾸면 하나하나 고쳐야 하고, 빠뜨린 것은 작동하지 않습니다 |

## 권장 방법: Hiddify로 컴퓨터 전체를 맡기기

1. [09 · 모든 플랫폼에 Hiddify 설치하기](09-hiddify-install-all-platforms.md)대로 Hiddify를 설치하고, [02](02-singbox-subscription-links.md)대로 프로필을 가져옵니다.
2. 'VPN' 모드(기본값)로 연결합니다. Windows에서는 처음 연결할 때 관리자 권한이 필요합니다.
3. 프로그램의 프록시를 '프록시 없음'으로 되돌립니다. Dropbox는 '기본 설정 → 네트워크 → 프록시'(Preferences → Network → Proxies)에서 '프록시 없음' 또는 '자동 감지'를, Telegram Desktop은 '설정 → 고급 → 연결 유형'(Settings → Advanced → Connection type)에서 '프록시 사용 안 함'(Disable proxy)을 고르세요. 프록시 옵션이 있는 다른 프로그램도 꺼 두세요.
4. 확인: Dropbox 트레이 아이콘에 '최신 상태'가 표시되고 동기화가 시작됩니다. 브라우저에서 IP를 보여 주는 웹페이지를 열면 출구가 고른 지역으로 나옵니다.

'자동 라우팅'을 켜 두면 Dropbox 같은 해외 서비스는 회선을 거치고, WeChat, 인터넷 뱅킹, 중국 웹사이트는 평소처럼 직접 연결됩니다.

## 자주 쓰는 프로그램

| 프로그램 | 설정 방법 |
|---|---|
| Dropbox | 프록시를 '프록시 없음' 또는 '자동 감지'로. '수동'에 다른 주소를 넣어 두면 Hiddify를 끄는 순간 오프라인이 됩니다 |
| Telegram Desktop | 연결 유형을 '프록시 사용 안 함'으로. 내장 MTProto / SOCKS5를 터널 위에 겹치면 느려지기만 합니다 |
| OneDrive, Google Drive, 데스크톱용 iCloud | 시스템 네트워크를 따르므로 설정할 것이 없습니다 |
| Steam, Epic, Battle.net | 프록시가 필요 없습니다. 다운로드가 느리면 더 가까운 지역으로 바꾸세요 |
| Zoom, Teams, Slack, Discord | 음성과 영상은 UDP라서 컴퓨터 전체를 맡기는 방식만 처리할 수 있습니다 |
| VS Code, JetBrains, Cursor | 시스템 네트워크를 따릅니다. 도구 안에 따로 설정한 프록시는 지우세요 |

## 클라이언트를 설치할 수 없을 때(회사 컴퓨터)

- Dropbox와 클라우드 드라이브는 웹 버전을 쓰세요. [웹 프록시](03-web-proxy-extension.md)를 켠 브라우저에서 dropbox.com을 열면 업로드와 다운로드는 되지만 자동 동기화는 없습니다.
- 명령줄 도구(git, pip, npm, curl)는 암호화된 프록시를 받습니다. 웹 프록시 주소를 `https_proxy`에 넣으세요. [중국에서 해외 서비스 접속하기 05 · Linux와 명령줄](https://github.com/vipinus/guides-zh-CN/blob/main/overseas-access/05-linux-server.md)(중국어)을 참고하세요.
- HTTP / SOCKS5만 받는 다른 데스크톱 프로그램은 개인 컴퓨터나 휴대폰에서 쓰는 것이 좋습니다. 이것 때문에 회사 컴퓨터에 컴퓨터 전체용 VPN을 설치하지 마세요. 회사 보안 경고가 울립니다.

## 자주 묻는 질문

**SOCKS5나 HTTP 프록시 주소를 받을 수 있나요?** 이 사이트의 프록시는 처음부터 끝까지 암호화된 연결을 씁니다. 암호화되지 않은 프록시는 머지않아 됐다 안 됐다 하게 됩니다. Hiddify로 컴퓨터 전체를 맡기는 편이 더 안정적이고 모든 프로그램을 한 번에 처리합니다.

**Hiddify를 켰는데 프로그램에 프록시를 또 입력해야 하나요?** 아닙니다. 입력하면 두 번 돌아가게 되어, 잘해야 느려지고 심하면 연결되지 않습니다.

**휴대폰의 Dropbox는요?** 휴대폰 앱에는 프록시 설정이 없습니다. Hiddify를 설치하거나 Cisco(AnyConnect)를 쓰면 연결되는 순간 모든 앱이 회선을 거칩니다.

**Hiddify 없이도 되나요?** 됩니다. Cisco, 사설망, OpenVPN도 컴퓨터 전체를 맡으며, 프로그램은 마찬가지로 '프록시 없음'으로 둡니다. Hiddify의 장점은 라우팅이 내장되어 있고 패킷 손실이 심한 네트워크에서 더 빠르다는 점입니다.
