# 공유기와 집 네트워크 가이드

집 안의 모든 기기를 한 번에 VPN에 연결합니다. 펌웨어가 설치된 공유기로 시작하기, 펌웨어 직접 올리기, 분할 라우팅의 원리, TV와 부모님, 공유기 연동과 교체를 다룹니다.

**가장 많이 찾는 글: [공유기로 해외에서 중국 동영상 사이트 차단 풀기](06-unlock-chinese-video-with-router.md)** — TV, TV 박스, 집 안 모든 기기를 한 번에 설정하고, 와이파이에 연결하기만 하면 아이치이(iQIYI), 텐센트 비디오, 양스핀(CCTV)을 볼 수 있습니다.
