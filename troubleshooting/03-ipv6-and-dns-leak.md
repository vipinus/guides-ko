# 03 · 연결했는데도 동영상 사이트에 저작권 안내가 뜰 때: 새는 곳은 IPv6와 DNS

> 웹사이트 버전(더 자세함): https://www.leotun.com/ko/guides/overseas-video?utm_source=github&utm_content=troubleshooting-03

[02 · 중국 회선에 연결했는데도 볼 수 없을 때](02-still-blocked-after-connecting.md)의 1단계는 통과했습니다. 출구 IP를 조회하면 중국 본토로 나옵니다. 그런데도 사이트에는 '저작권 제한으로 재생할 수 없습니다'라고 뜹니다. 십중팔구 기기에 VPN을 거치지 않는 길이 아직 남아 있는 것이고, 그 길은 **IPv6** 아니면 **DNS**입니다. 동영상 사이트는 자기에게 보이는 주소로 위치를 판단하므로, 한 군데라도 새면 여전히 해외로 보입니다.

## 왜 새나요

- 요즘 기기는 IPv4와 IPv6 주소를 둘 다 갖고 있고, 브라우저는 IPv6를 우선합니다. VPN이 IPv4만 맡으면 IPv6 요청은 집 인터넷 회선으로 그냥 나갑니다.
- 브라우저에 내장된 '보안 DNS', Android의 '개인 DNS', 함께 켜 둔 다른 메시 네트워크 도구(Tailscale 등)는 모두 VPN보다 먼저 이름 풀이를 가로챕니다.

'연결됨'은 터널이 만들어졌다는 뜻일 뿐, 모든 트래픽이 터널을 지난다는 뜻이 아닙니다.

## 5단계 점검

1. **IPv6 확인.** 연결한 뒤 'test ipv6'를 검색해 테스트 페이지를 엽니다. IPv6 칸에 지금 있는 나라의 주소가 나오면 → 여기가 문제이니 2단계로. 두 칸 모두 중국 본토로 나오거나 IPv6를 쓸 수 없다고 나오면 → 3단계로.
2. **IPv6를 끄거나, IPv6를 막아 주는 클라이언트로 바꾸기.** Windows: 네트워크 어댑터 속성에서 '인터넷 프로토콜 버전 6'의 체크를 풉니다. macOS: 네트워크 설정 → TCP/IP → IPv6 구성을 '로컬 링크 전용'으로. 휴대폰: 와이파이를 끄고 모바일 데이터로 한 번 시도해 보세요. 집 인터넷은 대개 IPv6가 있지만 통신사 모바일 데이터는 없는 경우가 많습니다.
3. **DNS 확인.** Chrome 설정 → 개인정보 보호 및 보안 → '보안 DNS 사용'을 끕니다. Android에서는 '개인 DNS'를 끕니다. 다른 VPN, 메시 네트워크 도구, 프록시 확장 프로그램은 종료하세요.
4. **앱을 완전히 종료했다가 다시 열고, 웹 버전이라면 사이트 데이터를 지우세요.** 플랫폼이 이전 지역 판정을 캐시해 둡니다.
5. **다른 입구로 바꿔 다시 시도하세요.** 특정 출구의 주소가 막 플랫폼에 표시되었을 수 있습니다.

## LeoTun은 이렇게 처리합니다

2026년 9월부터 LeoTun의 세 가지 연결 방식(Hiddify, Cisco AnyConnect, OpenVPN)은 모두 터널 안에서 IPv6를 바로 거부하고, 이름 풀이를 터널 안에서 하도록 강제하는 DNS 설정을 내려보냅니다. 기기에서 바꿀 설정은 없습니다. **9월 이전에 가져온 Hiddify 설정에는 이 규칙이 없습니다. 지우고 QR 코드를 다시 스캔해 가져오세요.**

공유기 방식은 애초에 새지 않습니다. LAN 전체가 공유기를 통해 나가므로 기기의 IPv6와 DNS가 바깥으로 나갈 일이 없습니다.

## 그래도 안내가 뜨는 경우

| 경우 | 증상 | 해결 |
|---|---|---|
| 출구가 중국 본토가 아님 | IP 조회 결과가 홍콩 / 대만 / 일본 | 중국 입구로 바꾸세요. 홍콩과 대만 주소도 텐센트 비디오와 아이치이(iQIYI)에는 해외로 취급됩니다 |
| 직접 만든 라우팅 규칙이 동영상 도메인을 '직접 연결'로 보냄 | 웹페이지는 열리는데 동영상이 재생되지 않음 | 중국 도메인이 노드를 거치게 바꾸세요. 해외 사용자는 '중국 직접 연결'을 켜면 안 됩니다 |
| 웹 프록시를 쓰고 있음 | 브라우저에서는 되는데 앱에서는 안 됨 | 동영상 시청에는 기기 전체 터널이 필요합니다. 웹 프록시는 브라우저만 처리합니다 |
